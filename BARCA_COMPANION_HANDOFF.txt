CURRENT BIG BALLS DATA INTEGRATION (PLAYER COVERAGE NOT YET LIVE-VERIFIED)
- The app keeps the API key in browser local storage; never include it in source or a ZIP.
- Upcoming games use GET /v1/matches?sport=football&league=laliga and league=ucl.
- The home page's Recent results card and form strip are refreshed from finished Barça matches in those same match lists and cached locally. Upcoming match dates/times are rendered in the America/Los_Angeles time zone with the correct PDT/PST abbreviation; date-only API entries show Time TBA.
- The home-page La Liga mini-table and Barça summary use GET /v1/standings?sport=football&league=laliga. It refreshes on app start and with LIVE DATA, and caches the latest response locally.
- Current La Liga stats first resolve FC Barcelona's team id from standings, then look up roster player ids from GET /v1/stored/players?sport=football&league=laliga&team=<team-id>&limit=200, and request GET /v1/players/{id}/club-form?season=2026. The free club-form route can provide appearances, goals, assists, minutes and cards when Big Balls has linked and stored the player row. The app falls back to the top-scorers leaderboard for players with no club-form row.
- A small app status message reports how many hard-coded listed players returned La Liga stats. The full unavailable-name list is saved locally in barca_companion_live_stats_status; no key is included.
- The documented API does not provide a current football club-roster capability. Keep the saved starting XI and do not label it a live full squad.
- The general /v1/players/{id}/stats route is documented as unavailable for football; use /club-form for its narrower supported football season fields. Current UCL season stats and goalkeeper saves/clean sheets are not supplied by these endpoints; show unavailable values as a dash, not zero. Goalkeeper cards may be populated if present in club-form.
- Do not claim the integration works until real responses have been tested using the user's key entered locally in the app.
